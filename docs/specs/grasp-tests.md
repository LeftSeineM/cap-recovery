# 资产抓取与晃动测试

入口为 `scripts/experts/eval_asset_grasp.py`（[运行与人工验收](../tutorials/08-asset-grasp.md)），复用场景的真实物理资产、专家的抓取候选与运动规划、机器人验收的桌子和工作点。每个环境只加载一个待测资产，不加载原场景的障碍物。

## 范围与协议

配置 configs/asset_grasp_000103.py 引用场景 000103 的资产清单，按资产路径去重：55 个实例、49 个资产，其中 39 个桌面可移动资产参与本轮。10 个背景设备或容器逐实例列出排除理由，不能当作通过。其他场景的资产用同样结构的配置接入；单个资产也可不经配置，用 `--asset` 和 `--robot` 直接测试。入口没有默认配置，不增加 metadata 字段。

全部直接放在桌面，不使用垫台；薄物体实际抓取失败照常记录。

本轮 39 个目标均为单刚体。带活动部件的资产需要另外定义要抓取的部件及其他刚体的保持条件，不能把本轮检查一个刚体相对 TCP 的结果推广为整套多刚体机构的通过。

- 默认测试中心为世界坐标 (0.50, -0.15) m（X1Pro RM001 验收工作点前方 5 cm），机器人朝 +X。默认每资产 20 个独立 seed，资产原点在测试中心周围 10 × 10 cm 方形内均匀采样，偏航在 [-π, π) 均匀采样；竖直方向选碰撞几何的稳定支撑姿态。这里随机的是桌面朝向，不是任意翻滚。
- 静置 0.5 s，目标抬升 10 cm、实测至少上升 5 cm 才进入持物动作（transport）验收；优先垂直向下接近，允许选左右手、调整躯干，不移动底盘。保存采样位姿、静置后位姿、最终握法、候选拒绝原因和规划日志。
- 持物动作的速度和加速度以强度上限（transport envelope）为界，强度上限取自成功专家轨迹的持物运动；分别施加平滑的横向、向上平移和手腕转动；不施加外力。平移行程为 50 mm，检验持物动作的加速度而不把长距离可达性混入夹持稳定性；转动行程约 1.002 rad。每段从静止出发并回到静止，最后保持 0.5 s。执行前在规划模型上预检整段动作：从当前保持的关节目标出发，各相邻位姿只做一次局部 IK，整段成功后才开始执行；不允许随机重启、缩短行程或放宽关节与 IK 限制。水平平移依次尝试朝中线的横向、反方向、世界 +X、世界 −X，每种都连同向上平移和手腕全行程一起预检，保持相同的加速度上限和总行程；手腕两侧分别预检完整行程，整段含持物碰撞检查，选择可达且无新增碰撞的一侧。当前起点没有等价选择可达时，先规划转移到可达的持物动作起点，再执行同样的验收动作（见下文）；转移或持物动作仍不可达时才记为 `not_evaluated`，单列并排除验收分母，不能算抓取失败。
- 每个控制步读取物体相对实测 TCP 的变换。平移跟踪“初始抓稳时 TCP 原点对应的物体上的点”，全过程最大位移须 ≤ 5 mm；独立计算相对转角，最大值须 ≤ 5°。两项同时满足才算稳，不能只比较最终位置。失去手指接触且握持点分离或物体下落超过 5 cm，单列为掉落。最大碰撞顶点位移继续记录为诊断量，不能代替上述平移判据。
- 原有 ±0.4 rad、每段约 0.5 s 的快速手腕往返只作为显式 `--diagnostic-shake` 的开发诊断，在持物动作验收通过后执行，结果保存在 `diagnostic_shake`，不改变验收状态。
- 物理步长沿用公共 0.004 s，控制频率 25 Hz；记录请求的强度上限、整段与各段实测峰值。持物动作的局部 IK 保留设计的 TCP 时间律，参考点转移路径沿用机器人 TOPPRA；两者均检查关节速度、加速度及 FK 的 TCP 速度、加速度，持物动作保留同一时间律，仅延长到满足约束的最短控制步数；完整保留行程，每段静止起止。25 Hz 记录不能代表物理子步的冲击峰值；穿透和接触仍作为诊断保存。

预检起点可处理输入关节配置的微小超限：越限量不超过 `1e-3` 时，将起始配置投影回硬限位，并以投影配置的 FK 作为动作原点；转动关节单位为 rad，直线关节单位为 m，与既有跟踪检查同口径。这是现有 `0.01` 到位误差预算的十分之一，仅用于输入起点，验收使用当前保持的驱动目标。超出此预算的起点直接记未评估；目标位姿、IK 解及关节限位均不放宽，也不裁剪 IK 解。条件文件的 `transport_start_projection` 记录预算、单位及原点规则，trial 的 `start_projection.measured` 保存输入配置的超限值，另存投影值、关节索引及原始/投影 TCP；没有超调时保持原起点。只裁剪 IK seed 不足以修复这个问题，因为原始目标 TCP 仍对应越限姿态。

抬升终点在工作空间边缘时，参考起点优先保持实测 TCP 朝向，将水平位置移到配置工作区中心，高度取所选握法的正常抬升目标高度；若该参考位姿不能完整预检，则使用机器人测试配置声明的关节姿态。参考姿态先通过全部持物动作的局部连续预检，再用既有的避碰 RRT 转移，抵达后按实测状态重新预检。普通规划可以选择关节分支，验收动作的局部 IK 仍只做单次连续求解。转移不重设物体相对 TCP 的参考位姿，滑移、转动和掉落同样计入验收；其间物理失稳记失败，不以转移未完成改记未评估。手指继续闭合，其他手臂按共用规划规则避让。强度上限、行程、阈值、规划预算与跟踪检查均不因转移而放宽。转移抵达时若触发跟踪检查，保留原始错误，从实际停留位姿重新预检；只有该位姿能完整执行原持物动作，才继续评估，不能直接把转移完成当作抓稳。

### 强度上限的依据

强度上限取成功专家轨迹的 P99：线加速度 1.12865 m/s²、角速度 1.22769 rad/s、角加速度 3.00874 rad/s²。统计区间、差分方法与推导见[实验台账](../experiments/20261026-asset-grasp/README.md#为什么)。使用升余弦 `x=A(1−cos(ωt))`，峰值速度 `Aω`、峰值加速度 `Aω²`。转动由角速度和角加速度确定 `A=v²/a≈0.50094 rad`，周期约 2.564 s；平移以 50 mm 行程确定 `A=25 mm`，周期约 0.935 s。周期向上取整为控制步的整数倍，平移峰值速度约 0.168 m/s。平移行程由测试工作区限定。每段以主导加速度实测峰值达到强度上限的约 90%–100% 为强度目标；关节或其他运动约束要求延时的段单列实际比例，不能声称达到 P99 强度。实测允许下述离散容差，完整保留行程。

动作验证使用 25 Hz 实测 TCP 的一阶、二阶差分，连续检查参考点转移、两段平移、转动与保持，包括段间边界。允许一个控制周期的相位误差：速度容差为 `a_peak × 0.04 s`，加速度容差为升余弦的 `jerk_peak × 0.04 s`，其中 `jerk_peak = a_peak × sqrt(a_peak/A)`。线速度、线加速度、角速度、角加速度的绝对容差分别约 0.045 m/s、0.303 m/s²、0.120 rad/s、0.295 rad/s²；持物动作指令按强度上限本身约束，参考点转移预留这份误差；验收时只在实测超过上限加容差时判为动作无效。每段实测峰值/强度上限的均值、最小值与受约束低于 90% 的段另列，不用动作有效代替达到测试强度。条件文件保存 `motion_limits` 与 `motion_tolerance`，实现见[持物动作](../../table_1000/experts/asset_grasp/transport.py)。

### 共用抓取策略与偏好数据

预测候选闭合时，先排除完全落在手指开合路径的闭合轴投影范围之外的碰撞面。物体受到手指推动后可以对中，但远处部件不能靠虚拟平移进入空手。范围由实际手指几何及开口决定，沿用既有接触容差；与范围相交的实体保留真实面，不把范围边界变成新的支撑面。若第一接触只是小边缘，仅在两侧各自既有的接触容差内继续检查能否建立足够支撑片；不能越过该层接受握法，第一接触已有效时保持原结果。接触面积和跨部位抗扭尺度使用同一有限范围。此约束只限定候选预测；执行后的闭合检查与默认有限重抓规则见下文。

候选和闭合检查与专家共用，不使用资产测试专属的宽松接触面积、25 mm 闭合容差或支撑穿透参数。候选方向和避障仍使用拟合形状，自由搬运时，所选部件用于生成候选方向与位置；闭合位置、接触面积与指腹边缘余量使用同一刚体的全部真实碰撞表面，保留凸块间的空隙，防止相邻部件提前挡住手指却仍按局部薄片预测开口，避免包围盒填满弯曲、斜面或空隙后虚增可夹区域。圆柱候选的切向接触层面积不能代替中心截面的插入深度：实际接触的每个凸块分别检查最宽截面是否进入指腹末端安全边距，支撑区域取并集，不把凸块间空隙算作某个截面的厚度；远处未接触的部件不参与该截面检查。箱形候选保留真实指腹内部接触层判据，平面局部支撑不要求包住整块碰撞体的最宽截面；原有阈值不变。张手接近、预抓取和闭合后的掌部也检查同一刚体的全部碰撞块；选中的部位名不能让手指穿过同名的其他凸块。已有候选包络覆盖的凸块不重复检查，其余凸块逐个保留，不能将鳍片之间的空气填成实心。复合刚体沿接近方向后退时，接触可从某一凸块的边缘转到另一凸块的完整表面，因此某个截面没有对向接触或接触面积不足时，继续检查既有范围内的后退位置；不能沿用单一凸体截面只会变小的提前终止假设。受关节约束的把手操作沿用原有候选规则。

近似凸的整物、实体部件和已有碰撞凸块用于枚举候选，定向包围盒保留细杆真实宽度。资产测试保留每个部位原有的共用候选顺序，在各部位当前首选之间按物理负载选择，再进行可达性与运动规划；只有当前候选被考虑后，才暴露该部位的下一候选，避免部位体积顺序压过抗扭能力，同时保留部位内部已验证的顺序。整物包络只在所有真实部位均找不到合法抓取时作为后备；第一次物理闭合或抬升失败不能因此转用后备重抓。仍保留手臂、升降阶段及原有规划预算。某部位的最小有效接近角已超出当前阶段范围时，该阶段整段候选没有可用项，直接跳过；后续可动升降阶段仍按原部位顺序和重试编号重放，不逐个生成已知全部会被过滤的握法。

几何居中和接触面积成本保持共用策略原有定义，另加入真实刚体质心产生的重力对夹持线的力矩。用 `τg = mg |((c−p)×z)·n|`，其中 `p` 为握持点、`c` 为实测质心、`n` 为闭合轴；沿夹持线的偏移不会产生绕线力矩，完整质心距离也保存在报告中。跨部位负载成本为 `τg / [r(N左+N右) cosθ]`，不叠加到部位内部原成本。`r` 为真实指腹接触片绕其中心的平均面内半径，按各采样单元均匀压力积分，取两侧中较小者；`cosθ` 为接触法向对闭合轴的平均绝对投影，取较差一侧。`normal_redirection_cost` 仅记录法向偏斜的 `tanθ`，不重复计入跨部位负载。`part_load_cost` 保存跨部位负载，`predicted_torsion_scale_Nm` 保存抗扭尺度；二者是排序信息，不是验收阈值。

法向力由当前驱动的刚度、闭合位置误差、力矩上限和手指开口的导数按虚功关系估计，不修改任何驱动值：转动手指 `N=min(K|q(g)−q(0)|, effort_limit)/|dy/dq|`，滑动手指直接使用闭合力。这里使用单位切向力比例作为排序的机械负载尺度，不把它当成未知摩擦和接触压力分布下的稳固保证。不能除以物重来替代夹持力，否则会隐含夹持力随物重变化的假设，并过分影响轻物体的排序。关节约束的非根刚体（例如滑轨上的抽屉）按所选把手操作，不套用自由悬持的力矩成本；自由搬运的 articulation 根刚体仍使用质量与质心。

转动手指张开后指腹不平行。按机器人手指的枢轴几何计算转角，厚度为两倍既有 1 mm 接触层的平面接触带宽为 `2 mm / |sin(θ)|`。接触带不足两侧既有 2 mm 边缘余量时，排除只靠边缘接触的候选；其余按损失的接触带比例计成本。共用闭合信号检查两侧指腹是否接触目标刚体，单有指尖或指身接触判为未夹实。CPU 使用原始 collider 路径区分同一 link 上的指腹；GPU 张量报告只有 link 和接触点，结合真实指腹碰撞几何定位。闭合开口与真实碰撞表面的预测比较，不再与填满空洞的包围盒比较；误差预算为两侧各 1 mm 接触层、0.5 mm 手指几何网格和 0.5 mm 闭合求解分辨率，共 3 mm。专家还须同时满足两项条件：实测开口不得比所选候选的计划接触开口少超过 5 mm，实测物体/TCP位姿下估计的指腹内部夹持面积至少为 5 mm²。真实表面与指腹接触检查和这两项条件须同时满足，检查失败走已有的有限重抓流程；记录中保留计划开口、两种开口容差、夹持面积及各项判定。本测试通过 `grasp(..., closure_only_record=True)` 只记录全部信号，不松手重抓，也不据此判失败。实际结果由抬升和持物动作确定。

持物动作指令从当前保持的驱动目标连续出发，保留持物负载下的位置驱动静态误差；不能把目标瞬间改成滞后的实测关节值。TCP 的验收与稳定性测量始终使用实测状态。参考点转移也从当前驱动目标平滑接入既有规划路径，避免抵达后重新起步时释放驱动预载。

每个 seed 的验收只看第一次执行当前专家策略的抓起与持物动作验收，`success` 与 `first_attempt_success` 含义一致。规划阶段可选择候选，资产测试内的闭合检查只记录，第一次闭合后直接抬升；实际抬起失败就结束本次验收，不用换部位后的成功覆盖它。持物动作验收失败后，恢复同一初始摆放，排除已实际尝试的部位，并在剩余部位之间重新统一排序；这些结果仅作为握法偏好数据。首次完整报告保留在 trial 顶层；`preference_attempts` 仅保存额外尝试，`first_attempt_timing` 保存首次耗时，顶层耗时累计全部尝试。`preference_data.by_grasp` 按部位 × 资产坐标系下带符号的接近轴和闭合轴统计实测稳定率，供后续候选排序参考。分组保留具体位姿；抬升失败是实际测得的失败，转移或持物动作途中已观察到滑移、失稳或掉落的握法计为实测失败；纯规划或跟踪失败且没有测到稳定性的握法单列在 `not_evaluated_by_grasp`，不当成握法失稳。整段持物动作的全部等价选择均不可达的 `not_evaluated` seed，以及实测 TCP 超出强度上限的 `invalid_motion` seed 排除验收分母；抓取失败、执行错误和未产出报告仍在分母内。`expected` 为请求数，`assessed` 为验收分母，`not_evaluated` 与 `not_evaluated_reasons` 单列未评估数；`invalid_motion` 单列动作无效数，后者不计为资产夹持失败或握法失稳。

`closure_check.table` 将首次闭合信号与实测结果分成四格：预测夹实/未夹实 × 实际抓稳/失败；预测未夹实而实际抓稳是误判，预测夹实但抬升失败或持物动作中失稳是漏判。按实际失败原因细分，保留 seed、信号原因和部件。纯规划失败、没有实测真值，或动作无效的信号单列为 `unmeasured`，未执行闭合的单列为 `no_check`，不混入四格。它用于评价专家的重抓信号，不能代替实际验收，也不自动改变专家检查。

单目标先求最近合法接近角，固定躯干阶段仅生成既有角度限制内的候选，移动躯干阶段仍使用完整范围；同一状态内复用接触计算，不改候选、阈值或预算。其重试编号改为角度与成本排序前的离散几何组合编号（闭合方向、接近方向、滑动位置、手的翻转），在同一目标形状和枚举设置内跨阶段保持稳定，不再表示成本名次。`geometry_choice` 保存该编号。多目标仍保留各部位的完整成本流、原部位内重试序号及首选阻塞顺序；不能提前移除某部位的阶段外首选而暴露其后续候选。

自由搬运带有后续 `InHand` 要求时，当前位置的候选排序同时考虑接近方向和当前手腕的完整朝向。`orientation_deg` 记录完整转角，`approach_deg` 表示接近方向偏差；阶段范围和最近合法接近角只使用后者。手腕偏好只改变排序，候选仍须通过原有接触与规划检查。没有后续要求的抓取（包括 chain 的无要求后备）、受关节约束的操作，以及为底盘选择未来站位的路径沿用物理候选排序。角度成本定义见[抓取几何](../../table_1000/experts/grasps/__init__.py)。

## 运行与结果

配置声明 `SCENE`、`ROBOT`、`TRIALS`（每资产 seed 为 `0..TRIALS-1`）和 `EXCLUDED_INSTANCES`；可选 `ASSETS` 明确资产路径，否则使用场景中全部未排除的资产。资产根目录同时是正式结果的根目录。[资产布局](README.md#资产布局)规定文件位置，[操作手册](../tutorials/08-asset-grasp.md)规定运行命令和复核顺序。

正式验收要求从干净的 Git 提交启动，完整执行配置；评测与录像使用同一冻结来源，发布核查冻结来源记录。提交批次后可继续修改原工作区。部分资产、部分 seed、变更试验次数、指定录像或运行标签属于开发运行。正式验收保存全部 seed 的结果与轨迹，齐全后整体替换各资产当前验收目录。抓取失败是有效结果；执行错误、报告或录像缺失时不发布。每资产保留一条录像：按 seed 递增取首个失败，否则 seed 0；`summary.json.video` 保存 seed、规则和相对路径。

开发运行每次一个新目录，目录存在则报错。全部请求的 seed 都保存轨迹，仅显式要求时录制运行时录像。源码以提交号标识；脏开发运行的 `dirty.patch` 由公共批处理冻结工作文件时生成，包含未提交与未跟踪的非忽略文件，不复制源码目录。正式批次日志和临时结果可清理。失败返回非零退出码，已完成的开发结果保留。

每资产结果含 `summary.json`、`trials/<seed>.json`、`trajectories/<seed>.hdf5`，有录像时含 `videos/`。轨迹保存每个控制步后的机器人与物体完整状态，含偏好搜索、复位跳转和阶段字幕；采样率 25 FPS，回放按记录状态渲染。`conditions.json` 与资产汇总记录配置路径和完整文本、协议、工作点、软件版本、运行名及 Git 提交。trial 的 `load`、`cpu_s`、`wall_s` 保存主机、负载、CPU 与墙钟时间。

汇总的 `success` 与 `first_attempt_success` 只计第一次抬升并通过持物动作；`assessed` 为实际完成验收的分母，`not_evaluated` 与 `invalid_motion` 分别单列不可达和动作无效数量。`closure_check` 是闭合信号与实际结果的四格表，`preference_data` 是按部位及资产坐标系接近轴、闭合轴分类的实测偏好。薄物体单列，不计一般尺寸物体结论。compare 读取当前协议的首次实际状态，不推算旧协议的首次代理结果；历史实验按对应提交复现。

`hold.motion_peaks` 保存连续全过程的四项峰值，`hold.segment_motion_peaks` 按段保存相同指标并包含边界相邻采样；`hold.motion_valid` 与 `motion_violations` 保存动作判定及超限峰值。预检各段的 timing.constraint_ratios 记录命令关节速度、加速度及 TCP 峰值与对应上限的比例，数组顺序为升降关节、手臂关节；用于区分关节约束导致的强度不足。`hold.trace` 中的 `segment` 区分参考点转移及持物动作各段，转移期间沿用同一物体/TCP参考。`transport preflight`、`transport relocation`、`transport relocated preflight` 事件与 `hold.preflight.relocation` 保存方向选择、参考点、原始错误及抵达后的连续预检。`target_attempts[].lift_trace` 保存抬升各步接触 collider、指腹开口、TCP/物体位姿和控制间隔平均法向力；法向冲量除以 0.04 s，表示平均值。`closure` 保存质量与质心。`initial_unreachable` 单列初始未执行抓取的数量；闭合后失去可达性归入 `object not held`，原始规划信息保留。

## 已知限制

强度上限按 25 Hz 的 TCP 记录验证，不能保证物理子步的冲击峰值。动作无效的 trial 保留实测信号、失稳和掉落记录，单列排除夹持验收分母；需要修正跟踪后重测。

LCD 等带薄板边缘的组合体，几何候选仍可能优先夹住薄边；部位名称不同也不保证实际接触不同的实体表面。当前接触片指标不能保证这种握法能带起物体，应复核 trial 的接触与抬升结果、记录轨迹及录像。

辅助夹具等偏心、薄底座组合体仍可能绕夹持线转动后脱离。候选接触片大小、法向与重力矩只提供几何偏好，不能替代真实接触压力、摩擦分布和持物动作验收；不能据此保证所有正常尺寸组合体均能稳定抓取。扁平大件及薄片的桌边夹取另行验证，本协议保留其失败结果，不把它们计入一般尺寸物体的结论。
