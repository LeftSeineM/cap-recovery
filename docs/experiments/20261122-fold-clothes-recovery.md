# 叠衣服接管中的夹爪触点换算

2026-11-22，实验草案 v0.1。

`fold_clothes / selector2 / L45` 的原始接管点为第 185 步，任务预算共 500 步。首轮用袖口坐标作为手腕目标，沿用回零姿态，两次提拉均未夹住。

检查五条同款衣物的原生成功示范。夹爪合拢时，布料触点沿手腕参考系 X 正向偏移约 146–156 mm。用当前布料网格确定世界坐标中的目标触点，按抓取姿态旋转手腕局部偏移，再从世界触点减去该偏移量。

本次 ARX X5 试验使用 150 mm 名义值。调用者传入工具的偏移，函数使用米和 wxyz 四元数。实际试提使用了仿真布料网格。

修正后的试验在第 262 步通过了袖口试提检查。第 264 步的横向搬运受两腕间距保护拦截。完整叠衣、放手撤回及原生成功终局仍待验收。
