# 资产抓取测试与专家耗时

场景 000103 的 29 个一般尺寸资产，在同一套新测试下，第一次抓取就抓稳的比例从原抓取策略的 74.5%（r0）提高到 95.2%（r15），每次首次抓取的 CPU time 从 30.7 s 增加到 132.1 s。经 #93 等性能优化后（#105 合入时的 main），成功率保持 95.2%，CPU time 降到 67.7 s，其余 27 个资产为 48.4 s。旧测试下原抓取策略为 60.9%，旧测试的来回晃动比新测试的持物动作剧烈得多，不能和新测试直接比较。三个专家场景合计成功 56–60/60，各节点之间的差别在 main 上 97–99% 成功率的波动范围内。新测试的持物动作经 #92 改为整臂混合运动后，实测强度达到专家持物运动 P99 的 93%–95%。剩下的局限是水瓶和辅助夹具仍然慢（308 s、349 s），辅助夹具几乎抓不稳。

关联：#42，PR #54；抓取策略消融的实验代码在 PR #107（不合入）。逐资产、逐场景的数字以及 commit 和命令见 [assets.csv](assets.csv)、[experts.csv](experts.csv)、[queries.csv](queries.csv) 和 [ablation.csv](ablation.csv)。

## 为什么

**为什么资产测试慢得多，专家几乎不受影响。** 新增的计算都在挑选握法上：每个候选都要对真实碰撞面做接触查询，并按重力力矩和抗扭能力打分。资产测试一次试次的物理仿真只有约 15 s，其余时间几乎全花在挑握法上，所以增加得多。专家 episode 的大头是物理仿真、RRT 规划和放置等子任务，挑握法只占一小部分。水瓶的碰撞面片多，一次试次要比较约 800 个候选。辅助夹具有 18 个可抓部件，首次失败后还会换一个部件再试一次以收集握法偏好，这一次也计入耗时。#93 把碰撞面查询改为批量求交、候选按需生成后，首次抓取 CPU 从 132.1 s 降到 67.7 s，水瓶从 991.8 s 降到 307.9 s，辅助夹具从 1005.8 s 降到 348.6 s（都只算首次抓取）。

**为什么换评价指标。** 旧测试是：抬起后手腕在 ±0.4 rad 之间来回摆动，每段 0.5 s，端点瞬间反向；看物体顶点位移是否不超过 5 mm；失败后换握法重试，任意一次通过就算通过。它有三个问题：
- 摆动远超专家实际的持物运动，会把专家够用的握法判成失败；
- 顶点位移随物体尺寸放大，大物体只要轻微转动就超限；
- 重试掩盖了"第一次抓不稳"，而专家第一次失败就要回滚重来。

新测试只看第一次抓取。抬起后拿着物体做三段平滑的持物动作：横移 50 mm、上移 50 mm、手腕转动约 1 rad。判据是握持点相对 TCP 的位移不超过 5 mm、转角不超过 5°。持物动作的强度上限是专家持物运动的 P99：线加速度 1.13 m/s²、角速度 1.23 rad/s、角加速度 3.01 rad/s²，取自 000002 的 264 条成功轨迹中的 530 个持物区间。够不着的记为"未评估"，实测速度或加速度超出强度上限的记为"动作无效"（这次持物动作比规定的更剧烈，掉了也不能说明抓不稳），都单列，不算夹持失败。

#92 把三段持物动作改为整臂混合运动：每段都允许伴随的平移或转动，指令定在强度上限的 95%，实测强度均值达到上限的 93%–95%（此前只有 23%–42%）；验收只看实测握持，取消"动作无效"类别。上表 r0、r15、#105 三行用的都是 #92 的测试流程。

## 局限

- **两个资产仍然慢。** #93 之后水瓶 307.9 s、辅助夹具 348.6 s，是其余 27 个资产均值的 6–7 倍；辅助夹具首次抓稳只有 0/20。

## 附录：迭代过程

**改动：**

- r1：换成新测试；闭合时检查真实指腹接触；候选按重力力矩排序。
- r2：持物动作预检四个等价方向；圆柱件要求指腹插到中心截面。
- r3：各部位按重力力矩与抗扭能力统一排序；指腹支撑按真实接触层计算。
- r4：改评价流程，不改抓取策略：原地做不了持物动作时，先挪到可达的参考起点再测，此后不再出现"未评估"。
- r5：复用角度预检时已经算过的接触。
- r6：真实碰撞面的射线求交用 Numba 编译。
- r7：接触小矩阵的计算限制为单线程 BLAS，消除 r6 带来的线程空转。
- r8：先检查平行约束面。
- r9：合入 main（含 #69）并整理模块；对照的 main 从 `3150aee` 换成 `f5c6be7`。
- r10：同一凸块、同一方向复用查询计划。
- r11：先检查完全闭合，用外包粗筛排除不可能相交的查询。
- r12：用完整转角作为枚举下界。
- r13：按完整手腕转角排序，只用于有后续手持要求的抓取。
- r14：持物动作限速，并检查实测速度和加速度是否超出强度上限（审查修复）。
- r15：在关节上限内取最短时间，并对持物做整段碰撞预检（复审修复）。
- r16：#92 把持物动作改为整臂混合运动：锁住升降，三段都允许伴随的平移或转动，指令定在强度上限的 95%，实测强度达到专家 P99 的 93%–95%；验收只看实测握持，取消"动作无效"。抓取策略不变。从这一行起都用这套测试，初始和 r1 的抓取策略也在这套测试下复测（实验分支 #107 上的策略开关）。
- r17：#93 碰撞面查询批量求交、候选按需生成。同期 main 还合入了 #59（薄物体桌面取物）和 #99（合并刚体按物理刚体拟合部件）。
- r18：#105 包围盒先用原始点、出错才修复凸包，修复 #99 引入的 scope_probe 回归。
