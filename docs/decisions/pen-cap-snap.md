# 可拆装笔帽：原生钢珠弹簧卡扣

## 决定

笔帽的保持与脱离用 PhysX 原生接触和关节表达：笔颈有一圈凸棱，笔帽内有三颗钢珠，每颗钢珠通过径向滑动关节连接帽壳，关节的弹簧驱动把球压向笔颈。拔出和压入时凸棱推动钢珠向外，越过凸棱后弹簧使钢珠回位。

每支笔有笔身、帽壳和三颗钢珠共五个刚体，视觉上仍是笔身和笔帽两个组件，钢珠只用于碰撞。参数与几何由资产的 `physics.py`、`object.py` 维护，经统一入口生成 USD 资产（见[物理属性](../specs/physics.md)与[第二章](../tutorials/02-physics-assets.md)）。

## 依据

- 保持与脱离由接触和弹簧共同求解，不需要脚本识别配对、施加保持力、吸附或解除连接；兼容笔帽可以直接交换，重力、夹持和其他物体的接触自然参与同一求解。
- 实现了弱拉保持、强拉拔出、重复盖合、两帽互换，以及紧帽保持、未越过卡扣的松帽翻转后滑落。
- 资产只用原生 USD 表达，分发和维护比自行计算保持力或依赖额外插件简单。性能与 BrickSim 方案相近。

## 适用边界

- 这是用于装配任务的等效机构，没有模拟真实笔帽的塑料过盈和形变；质量、摩擦与弹簧均未经实物标定，钢珠质量是工程代理值。
- 适合低速装配和宏观跌落演示，不能预测真实的脱帽高度或冲击载荷。4 ms 步长下高速冲击有瞬态穿透，卡扣是否越棱也随步长变化；验收看是否稳定恢复，不以瞬态穿透单独拒收。
- 验收围绕四个过程：紧松两帽拔出、轻推停在卡扣前再加力盖紧、三高度同时跌落、紧松两帽从朝上转到朝下（实测值见[笔的 README](../../asset_sources/objects/pen/000002/README.md#物理实测)）。

## 未采用的方案

| 方案 | 原因 |
| --- | --- |
| 脚本计算等效保持力 | 需要不断补充外力来源和状态规则（重力、夹具、接触） |
| 原生柔顺接触或径向弹性预压 | 测试的原型出现重插卡滞、预压丢失或明显的步长敏感 |
| 限力驱动加可分离约束 | 仍需配对与解除逻辑，位置驱动有回座趋势，测试版本重插时会解除 |
| Surface Gripper / Robot Assembler | 用于抓取连接或固定装配，断裂参数与轴向保持力不对应 |
| Factory / IndustReal、RoboDojo 装配任务 | 只判断插入是否成功，不检查撤去夹具后的保持、抗拔和反复拆装 |
| 柔性体与压力接触 | 静摩擦、运行环境或计算成本受限，需求不需要完整的材料形变 |
| BrickSim 连接与承载 QP | 松放时会落座自动连接并锁定旋转，还需维护原生插件及版本相关接口 |

参考：[BrickSim](https://github.com/intelligent-control-lab/BrickSim)、[Isaac Lab Factory](https://isaac-sim.github.io/IsaacLab/main/source/overview/environments.html)、[RoboDojo](https://github.com/RoboDojo-Benchmark/RoboDojo)。
