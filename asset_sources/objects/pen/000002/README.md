# 蓝色钢珠卡扣粗笔

![preview](three_quarter.jpg)

蓝色连续笔杆带浅色标签和半透明笔帽，约 179 × 20 × 20 mm。笔身、帽壳和三颗内部钢球，共 **5 个物理刚体**。帽沿 −X 拔出；三球通过径向滑动关节连接帽壳，行程 0–0.8 mm。球仅在碰撞预览显示。

原生钢珠弹簧卡扣；参数为未标定工程代理。

CPU PhysX 对五个刚体统一开启 CCD，避免钢珠在 4 ms 步长的落地过程中穿过薄板后被弹簧关节夹在板下。GPU 管线关闭状态回读时 PhysX 会禁用 CCD（见[物理测试](../../../../docs/specs/physics-tests.md)），所以 GPU 后端上钢珠仍可能穿过薄板；其余机械参数相同。

```text
body [rigid]
  barrel
  detent_ridge
  label
  neck
  tip
cap [rigid]
  end
  lip
  shell
cap_ball1..3 [rigid]
  ball
```

## 物理实测

Isaac Sim 5.1.0 / Isaac Lab 2.3.2，4 ms 步长；CPU 后端 1 个环境，GPU 后端 4 个并行环境。未标定的仿真值。

| 物理量 | CPU | GPU | 测试与测量方式 |
| --- | --- | --- | --- |
| 拔帽力（紧帽） | 2.36 N | 2.73 N | `pull_comparison`：夹持笔帽以 5 mm/s 沿 −X 拉出，取拉力峰值 |
| 拔帽力（松帽，初始开口 3 mm） | 0.007 N | ≈ 0 N | 同上 |
| 合帽力 | 3.74 N | 2.14 N | `close`：夹持笔帽只沿笔轴推（横向由笔杆导向，姿态保持），0.3 N 限力推到卡扣前停住，然后以 0.6 N/s 提高上限，取盖紧（开口 < 0.2 mm）前的最大推力 |
| 0.2 / 0.5 / 1 m 跌落后笔帽松出 | 0.16 / 0.23 / 0.29 mm | 0.36 / 2.23 / 3.50 mm | `drop_heights`：自由跌落并静置后，取各落高最后时刻的帽口位移 |
| 重力翻转 180°（30°/s）后的状态 | 紧帽保持，松帽滑落 | 紧帽保持，松帽滑落 | `gravity_rotation` |
| 跌落后笔帽被震出的距离（0.2 / 0.5 / 1 m） | 0.3 / 4.3 / 12.9 mm | 0.4 / 2.2 / 3.5 mm | `drop_heights`：三支笔同时落地，落地后稳定下来 |

CPU 与 GPU 的合帽力相差约 1.7 倍，见 [#15](https://github.com/xucj98/table-1000/issues/15)。GPU 合帽力在 1 个环境时为 2.13 N：合帽过程对求解顺序敏感，环境数改变后结果略有不同。

GPU 跌落实验采用 PGS，其余测试采用 TGS；CCD 关闭的 GPU 跌落松出量较大。

性能（四项测试的范围；`--benchmark` 三轮独立新场景测量，无渲染 RTF 取每项三轮中位数，RTF按单个环境计）：

| 后端 | 无渲染 RTF | 含视频 RTF | 本进程 CPU 占用 | GPU 利用率（无渲染 / 含视频） |
| --- | --- | --- | --- | --- |
| CPU，1个环境 | 0.19–0.46 | 0.19–0.30 | 1.29–2.24核 | 6.3–6.6% / 4.3–7.6% |
| GPU，4个环境 | 0.08–0.16（合计 0.31–0.62） | 0.07–0.12（合计 0.29–0.48） | 1.21–1.37核 | 28.4–53.8% / 25.0–45.3% |

2026-10-25测量，AMD EPYC 7542加RTX4090，与其他任务共享；各测试结果记录的1分钟负载为47–119，显卡上共有3–7个计算进程（含本进程）。GPU利用率是整卡数据。新资产与旧资产的性能数据来自不同背景负载，不能据此单独估计CCD开销。
